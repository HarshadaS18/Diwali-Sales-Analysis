# 🎯 Diwali Sales Analysis

This project performs Exploratory Data Analysis (EDA) on a Diwali Sales dataset to uncover purchasing patterns based on demographics.

---

## 📁 Files Included
- ✅ `Diwali_Sales_Analysis.ipynb` — Jupyter Notebook with complete EDA
- ✅ `Diwali Sales Data.csv` — Dataset used for analysis
- ✅ `Diwali_Sales_Analysis.pdf` — Report version in PDF
- ✅ `README.md` — Project summary and details

---

## 📌 Key Insights:
- Most buyers are **married women aged 26–35**
- Top states: **Uttar Pradesh**, **Maharashtra**, **Karnataka**
- Common occupations: **IT**, **Healthcare**, **Aviation**
- Popular categories: **Food**, **Clothing**, **Electronics**

---

## 🧰 Tools Used:
- Python
- Pandas
- Seaborn & Matplotlib
